# Rebind 1.1.0

- Control G915 TKL lighting: brightness, color, idle timeout and low-battery colors. Lighting turns off when idle and comes back on when you press a key. Other compatible Logitech RGB keyboards and mice have experimental support.
- New actions include Spotlight, Emoji & Symbols, microphone mute, fast-forward, rewind and Fill with Left Margin.
- Reduced background work when Rebind is idle.
- Running an Apple Shortcut no longer delays releasing held keys or mouse buttons.
- Clearer action errors in the main window and menu bar.
- Improved wording in all six languages.

Download **Rebind.dmg**, open it and drag Rebind into Applications. If you already use Rebind, choose **Check for Updates…**.

Requires macOS 26 or later. The app is signed but not notarized; see the [installation guide](https://github.com/Blinks44/rebind#install) if macOS blocks the first launch. Tested on Apple silicon with macOS 27; macOS 26 and Intel remain untested.
