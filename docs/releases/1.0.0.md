# Rebind 1.0.0

First public release of Rebind, a free, open-source native macOS input remapper.

- Assign shortcuts and macOS actions to keys, middle/extra mouse buttons and supported touch gestures.
- Use press, double press, hold and short-press fallback; button + movement/wheel; held shortcuts and modifiers.
- Arrange windows, switch desktops, control media, open apps/files/websites, run Apple Shortcuts and insert text.
- Keep separate built-in/external trackpad bindings, manual profiles and per-app rules/exclusions.
- Tune mouse-wheel scrolling and supported Logitech settings; view available device battery levels.
- A short first-run guide; export/import backups and profiles; pause from the menu bar; signed automatic updates through Sparkle.
- English, Russian, German, French, Spanish and Simplified Chinese.

## Install

Download the **Rebind-1.0.0-11.dmg** asset below and drag Rebind into Applications. Quit the older copy before replacing it. The current candidate uses an Apple Development certificate for local testing and is not notarized by Apple; installation on other Macs is unverified. If macOS blocks launch, follow [the installation guide](https://github.com/Blinks44/rebind#install), then allow Accessibility for that copy. Verify the download using the attached **SHA256SUMS.txt**.

## Requirements and limits

- Requires macOS 26+. Recorded runtime checks are on Apple silicon with macOS 27; update this statement only after additional platforms are actually tested. Intel and minimum-OS execution are not yet verified.
- Touch gestures are experimental and use a private macOS interface. Trackpads offer 12 presets/category; Magic Mouse offers six tap/click/vertical-scroll presets. Overlapping native gestures may also respond; swipe, pinch and rotation are not supported.
- Caps Lock, Fn/Globe, modifier-only triggers and left/right modifier distinction are outside scope. Rules target input categories, not individual physical devices.
- Available device settings and battery readings depend on hardware and connection. Some actions depend on macOS shortcuts, permissions or the target app.
- Rebind checks GitHub once a day for a signed update and asks before installing (turn it off in Settings → General). Settings stay local; text explicitly saved in Insert Text rules is unencrypted. Rebind keeps no typing history and sends no analytics.

See the [user guide](https://github.com/Blinks44/rebind/blob/main/docs/USAGE.md) for examples and recovery and [report a bug](https://github.com/Blinks44/rebind/issues/new/choose) with your version, macOS, device and reproduction steps. Do not post configuration files or private input.
