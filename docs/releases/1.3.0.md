# Rebind 1.3.0

- Rebind now runs on macOS 15 Sequoia and later.
- Magic Mouse: tap the left or right half with one finger to run a separate action. Experimental, like the other Magic Mouse gestures.
- The update window now shows what changed.
- The setup window no longer shows Check Again once access is granted.

Download **Rebind.dmg**, open it and drag Rebind into Applications. If you already use Rebind, choose **Check for Updates…**.

Requires macOS 15 or later. The app is signed but not notarized; see the [installation guide](https://github.com/Blinks44/rebind#install) if macOS blocks the first launch. Tested on Apple silicon with macOS 27 and in a macOS 15 virtual machine. Trackpad and Magic Mouse gestures on macOS 15, macOS 26 and Intel Macs are untested.
