# Rebind 1.3.1

- Fixed built-in trackpad gestures stopping after the Mac slept for a long time with the lid closed.

Download **Rebind.dmg**, open it and drag Rebind into Applications. If you already use Rebind, choose **Check for Updates…**.

Requires macOS 15 or later. The app is signed but not notarized; see the [installation guide](https://github.com/Blinks44/rebind#install) if macOS blocks the first launch. Tested on Apple silicon with macOS 27. Trackpad and Magic Mouse gestures on macOS 15, macOS 26 and Intel Macs are untested.
