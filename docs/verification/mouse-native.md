## Implemented scope and source

Mouse detail uses the selected manual profile's category-wide rules, searchable trigger/action/activation, enabled state, edit/delete, empty/no-results feedback, profile controls, permission recovery and diagnostics. Conditional editor handles numeric middle/extra buttons with Press/Double Press/Hold, discrete wheel and four cardinal button-held pointer directions. It retains the shared action catalog and parameter controls. Separate capture fields retain previous values through cancellation, reject unrelated/wrong-type recording results and preserve output when input type changes. Editing preserves rule identity/enabled state; saving uses shared configuration validation and atomic persistence, with conflict feedback and retained storage-failure drafts. Permission recovery opens over the editor to retain its draft. Secure Input, stopped capture and suspended sessions disable recording; pause alone does not.

Changed source: `ContentView.swift`, `AppModel.swift`, `BindingEditor.swift`, new `BindingEditorDraft`, `BindingEditorValidation`, `BindingCaptureField`, `BindingEditorSection`, `MouseTriggerEditor`, `MouseBindingsView`, `MouseBindingRow`, `MouseBindingList`; 33 new manual String Catalog keys, all EN/RU/DE/FR, including two independent plural keys. About/catalog/sidebar changes already present were preserved. No schema, capture callback, matcher, dependency or action mechanism change.
